Assets Manager.

A home for the objects, sprites, and details that make a world yours.

CREATE ↓PNG TO SPRITES ↓A WORLD OF YOUR OWN ↓

CREATE & CUSTOMIZE

Start with an object. Make it yours.

The Assets Manager puts the building blocks of Centurion in one place. Create and edit the data behind units, buildings, decorations, and visual effects, then bring them into a world through the editor. It is part of our ambition to make modding central to the game.

  • Create and edit game object definitions.
  • Connect visual assets with object properties.
  • Build a collection for your own worlds.

PNG TO SPRITES

From artwork to animation.

Centurion pairs a three-dimensional landscape with two-dimensional sprites. The asset workflow is designed to turn PNG artwork into organized sprite animations, bringing frames and directions together so a character or building can find its place in the game.

  • Prepare sprite animations from PNG images.
  • Organize animation states and directions.
  • Preview the visual identity of your objects.

A WORLD OF YOUR OWN

Create once. Build on it.

A useful asset library is something you can keep returning to. By keeping object data and artwork organized, the Assets Manager helps connect the things you make with the maps you want to build. Our goal is to make that journey approachable for the next generation of Centurion creators.

  • Keep objects and their visual assets connected.
  • Use your collection in the Editor.
  • Help shape a moddable game from the ground up.
